================================================
Создание учётной записи Windows на латинице
================================================

*Библиотека алой дьяволицы · 16 декабря 2024*

В Windows мы часто используем учётную запись для работы и не задумываемся,
какая разница между именем на кириллице и латинице. Однако некоторые программы
не умеют корректно работать с путями, содержащими кириллицу, и требуют учётную
запись с латинским именем. Ниже показано, как создать такую локальную учётную
запись в Windows 10.

.. note::

   Интерфейс на скриншотах относится к Windows 10. В других версиях Windows
   названия пунктов и расположение настроек могут отличаться.

.. warning::

   Для создания и управления учётными записями необходимы
   **права администратора**.

Открываем параметры Windows
===========================

Нажмите **Пуск → Параметры** (значок шестерёнки).

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat1.webp
   :alt: Кнопка «Параметры» в меню «Пуск» Windows 10
   :align: center
   :width: 65%

   Открытие параметров Windows через меню «Пуск».

В окне параметров выберите раздел **«Учётные записи»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat2.webp
   :alt: Раздел «Учётные записи» в параметрах Windows
   :align: center
   :width: 75%

   Раздел управления учётными записями.

Добавляем нового пользователя
=============================

Откройте пункт **«Семья и другие пользователи»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat3.webp
   :alt: Пункт «Семья и другие пользователи»
   :align: center
   :width: 70%

   Переход к управлению другими пользователями компьютера.

Нажмите **«Добавить пользователя для этого компьютера»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat4.webp
   :alt: Кнопка добавления пользователя для этого компьютера
   :align: center
   :width: 85%

   Добавление нового пользователя.

В открывшемся окне выберите ссылку
**«У меня нет данных для входа этого человека»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat5.webp
   :alt: Ссылка «У меня нет данных для входа этого человека»
   :align: center
   :width: 85%

   Создание пользователя без данных существующей учётной записи Microsoft.

Затем нажмите **«Добавить пользователя без учётной записи Microsoft»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat6.webp
   :alt: Добавление пользователя без учётной записи Microsoft
   :align: center
   :width: 85%

   Переход к созданию локальной учётной записи.

Задаём имя и пароль
===================

В поле **«Имя пользователя»** введите имя латиницей, желательно без пробелов
и специальных символов. Например: ``ahri``.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat7.webp
   :alt: Поле имени нового локального пользователя
   :align: center
   :width: 85%

   Ввод имени локальной учётной записи латиницей.

Заполните поля **«Введите пароль»** и **«Введите пароль повторно»**. Пароль
понадобится, в частности, при запуске программы от имени другого пользователя.
Затем выберите контрольные вопросы, укажите ответы и нажмите **«Далее»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat8.webp
   :alt: Поля пароля и контрольных вопросов новой учётной записи
   :align: center
   :width: 85%

   Настройка пароля и контрольных вопросов.

.. important::

   Не используйте простые пароли вроде ``0000`` или ``1234`` для учётной
   записи, к которой могут получить доступ другие люди. Сохраните пароль и
   ответы на контрольные вопросы в надёжном месте.

После завершения новая локальная учётная запись появится в списке пользователей.

Как использовать новую учётную запись
======================================

Есть два основных варианта.

Смена пользователя
-------------------

Откройте **Пуск**, нажмите на значок текущего пользователя и выберите выход из
учётной записи либо новую учётную запись. После этого войдите под созданным
именем и паролем.

Запуск отдельной программы
--------------------------

Чтобы запустить только одну программу от имени новой учётной записи, удерживайте
клавишу **Shift**, щёлкните по программе правой кнопкой мыши и выберите
**«Запуск от имени другого пользователя»**.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat9.webp
   :alt: Пункт «Запуск от имени другого пользователя» в контекстном меню
   :align: center
   :width: 90%

   Запуск программы от имени другого пользователя.

В открывшемся окне введите имя и пароль новой учётной записи. Например,
имя пользователя ``ahri`` и заданный при создании пароль.

.. figure:: /_static/articles/operating-systems/windows/create-windows-account-latin/acclat10.webp
   :alt: Окно ввода имени и пароля другого пользователя Windows
   :align: center
   :width: 80%

   Ввод данных локальной учётной записи.

Готово. Теперь программы, которым мешает кириллица в пути пользовательского
профиля, можно запускать через созданную учётную запись.
