========================
Как добавить новую статью
========================

Новая статья создаётся отдельным файлом ``.rst`` или ``.md`` внутри папки
``docs``. Для обычных публикаций удобно использовать ``docs/articles``.

Шаг 1. Создать файл
===================

Скопируй ``docs/articles/template.rst`` и дай копии понятное имя латиницей,
например ``game-review.rst``.

Шаг 2. Написать материал
========================

Замени заголовок и заполни разделы статьи. Заголовки второго и третьего уровней
автоматически появятся в правом меню текущей страницы.

Шаг 3. Поставить статью на полку
===============================

Открой файл ``index.rst`` нужной полки и добавь путь к статье в её ``toctree``.
Расширение файла указывать не нужно.

Например::

   .. toctree::
      :maxdepth: 2

      game-review

Шаг 4. Опубликовать изменения
=============================

Сохрани изменения в GitHub. Read the Docs автоматически запустит новую сборку,
после чего статья появится на сайте.

Как создать вложенную полку
===========================

Создай папку с собственным ``index.rst``, добавь в него ``toctree`` со статьями,
а путь к этому ``index`` помести в родительскую полку. Так можно строить дерево
разделов любой разумной глубины.
