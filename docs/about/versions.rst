=======
Версии
=======

Библиотека развивается постепенно: меняется структура полок, оформление,
навигация и сами материалы. Номер версии сайта хранится в ``docs/conf.py``.

Текущая версия
==============

На данный момент в конфигурации указана версия **0.2.2**.

Как читать номер версии
=======================

Пока проект находится на раннем этапе развития, используется схема ``0.x.y``:

* ``x`` — заметные изменения структуры или возможностей сайта;
* ``y`` — небольшие исправления, оформление и точечные улучшения.

До версии ``1.0`` структура библиотеки может заметно меняться по мере роста проекта.
