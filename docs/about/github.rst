======
GitHub
======

Исходный код **Библиотеки алой дьяволицы** хранится в открытом репозитории GitHub.

Репозиторий
===========

* GitHub: https://github.com/Dreafun/libraryscarletdevil
* Сайт: https://library-scarlet-devil.readthedocs.io
* Основная ветка: ``main``

Как связаны GitHub и сайт
=========================

GitHub хранит исходные файлы Sphinx: статьи, настройки темы, стили и статические
ресурсы. Read the Docs получает изменения из репозитория и собирает из них готовый сайт.

Упрощённо цепочка выглядит так::

   GitHub -> Read the Docs -> Sphinx -> сайт

После изменения исходников и отправки их в ``main`` новая сборка сайта появляется
после успешного завершения процесса на Read the Docs.

Что находится в репозитории
===========================

* ``docs/`` — страницы и конфигурация библиотеки;
* ``docs/articles/`` — тематические материалы;
* ``docs/_static/`` — стили, JavaScript и изображения;
* ``docs/conf.py`` — основная конфигурация Sphinx;
* ``.readthedocs.yaml`` — параметры сборки Read the Docs;
* ``README.md`` — краткая информация о проекте для GitHub.

История изменений
=================

Каждое изменение репозитория сохраняется как коммит. Благодаря этому можно увидеть,
когда менялись статьи, оформление и структура сайта, а при необходимости сравнить
разные состояния проекта.

Сообщить о проблеме
===================

Если в статье найдена ошибка, неработающая ссылка или другая проблема, её можно
зафиксировать через раздел **Issues** репозитория GitHub. Для небольших исправлений
также можно предложить изменение через pull request.
