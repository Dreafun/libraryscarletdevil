=====================
Как устроены статьи
=====================

Материалы библиотеки хранятся как исходные файлы Sphinx и собираются в готовый сайт
через Read the Docs. Основной формат статей — reStructuredText (``.rst``),
но конфигурация также поддерживает Markdown (``.md``).

Иерархия библиотеки
===================

Статья всегда находится внутри тематической полки. Например материал о Windows может
располагаться по пути::

   docs/articles/operating-systems/windows/example-article.rst

Файлы ``index.rst`` внутри каталогов формируют полки и связывают материалы через
директиву ``toctree``.

Заголовки
=========

У статьи должен быть один главный заголовок. Далее материал делится на логические
разделы и подразделы. Эти заголовки используются Sphinx для навигации и формируют
оглавление справа.

Простой пример::

   ===============
   Название статьи
   ===============

   Введение
   ========

   Основная часть
   ==============

   Подраздел
   ---------

Имена файлов
============

Для файлов и каталогов используются короткие понятные имена латиницей, обычно в
``kebab-case``. Например::

   create-windows-account-latin.rst

Это делает адреса страниц предсказуемыми и уменьшает вероятность проблем со ссылками.

Изображения и другие ресурсы
============================

Статические файлы находятся в ``docs/_static``. Для крупных статей изображения
повторяют логический путь материала. Например::

   docs/_static/articles/operating-systems/windows/example-article/

Так ресурсы разных материалов не смешиваются в одной папке.

Добавление статьи в меню
========================

Создать файл недостаточно: его нужно добавить в ``toctree`` соответствующей полки.
Например::

   .. toctree::
      :maxdepth: 2

      example-article

После отправки изменений в GitHub Read the Docs собирает новую версию сайта.

Ссылки между страницами
=======================

Для внутренних переходов лучше использовать ссылки Sphinx, например::

   :doc:`Название ссылки <../about/index>`

Такие ссылки проверяются во время сборки и надёжнее ручных ссылок на HTML-файлы.
